Начало работы

Для recall нужен Mac с процессором Apple и macOS 13 или новее. При первом запуске он спросит три вещи:

  1. Где сейчас ваш дневник. Хранилище Obsidian на этом Mac находится автоматически. Можно выбрать любую папку с Markdown-файлами или начать новый дневник.
  2. Что перенести и где recall будет это хранить. recall копирует выбранные папки в свою библиотеку, по умолчанию iCloud Drive/recall. Оригиналы не меняются.
  3. Локальная модель. Однократная загрузка около 120 МБ. После неё recall работает без интернета.

Сочетания клавиш

  • ⌘N новая запись · ⌘K перейти к дате или найти по смыслу
  • ⌘1 лента · ⌘2 темы
  • ⌘L скрыть содержимое окна · ⌘, настройки

Где хранятся записи

Каждая запись — Markdown-файл в вашей библиотеке: recall/<коллекция>/ГГГГ/ММ/ГГГГ-ММ-ДД ЧЧмм.md. Их откроет любой текстовый редактор и Obsidian. Данные самого recall (настройки, поисковый индекс, названия тем и модель) лежат на вашем Mac в ~/Library/Application Support/recall.

Резервные копии: сохраняйте папку библиотеки, например с помощью Time Machine. Индекс восстанавливается из записей, если его нет.

Отклики и темы

Отклики (Echoes) — прошлые записи, близкие по смыслу к абзацу, который вы пишете. Они появляются на полях только при близком совпадении, поэтому чаще всего поля пустые.

Темы (Patterns, ⌘2) — то, что встречается минимум в 5 записях за 3 разные недели; они названы вашими же словами. В молодом дневнике их может ещё не быть. И то и другое можно выключить в настройках (Settings, ⌘,). Интерфейс recall пока на английском.

recall не толкует ваши записи и не даёт советов. Это инструмент для ведения дневника, а не медицинский или терапевтический сервис. Если вам сейчас тяжело, на findahelpline.com есть бесплатная и конфиденциальная помощь.

Записи с iPhone

В приложении «Быстрые команды» создайте команду recall. Даты форматируются на месте: вставьте Текущая дата, нажмите на неё и выберите формат «Свой».

  1. Запросить ввод (Ask for Input): текст, с разрешением нескольких строк.
  2. Текст (Text): текущая дата в формате yyyy-MM-dd HH:mm, пустая строка, затем «Ввод».
  3. Задать имя (Set Name): имя текста — текущая дата в формате yyyy-MM-dd HHmm и .md, с включённым «Не включать расширение».
  4. Сохранить файл (Save File): переименованный объект, без запроса места. Папка: iCloud Drive → recall → ваша коллекция. Вложенный путь: текущая дата в формате yyyy/MM и /.

Запись появится в recall на Mac, как только iCloud её синхронизирует.

Что-то не так

Запись с телефона не появляется

Проверьте её имя в приложении «Файлы»: оно должно заканчиваться на .md. Без шага «Задать имя» команда сохраняет .txt, а такие файлы recall не читает. Если имя верное, дайте iCloud минуту скачать файл на Mac.

Модель не загрузилась

Интернет нужен один раз. Закройте recall, проверьте соединение и откройте его снова, чтобы пройти настройку ещё раз. Уже скопированные записи будут узнаны, а не скопированы повторно.

Перенесённые записи оказались не в тот день

recall определяет дату записи по имени, если в нём есть дата, а иначе — по времени последнего изменения файла. Settings → Import → Import again восстанавливает исходные даты ранее перенесённых записей.

Поиск или отклики работают странно

Закройте recall, удалите index.db в ~/Library/Application Support/recall и откройте его снова. Он перечитает записи; в библиотеке ничего не изменится.
